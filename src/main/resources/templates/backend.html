Java & Spring Boot notes.

Practical concepts behind this website and my Java applications, without unnecessary scaffolding.

Spring MVC routing

Each major section of this website uses a dedicated controller and template. A controller handles incoming requests, supplies the page model and selects a Thymeleaf view.

@Controller
public class HomeController {
    @GetMapping("/")
    public String home() { return "index"; }
}

Thymeleaf rendering

Shared navigation and footer fragments keep the public pages consistent. Project detail pages are populated from a small static catalog, ready for an optional database later.

REST APIs alongside MVC pages

The project's original /api/welcome endpoint remains separate from the HTML routes and is preserved without changes.

Configurations and secrets

Application settings and CI/CD configuration remain unchanged. Sensitive keys should be supplied through environment variables rather than committed to source control.
